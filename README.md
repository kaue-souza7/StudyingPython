# 🐍 Repositório de Estudos em Python

Este repositório reúne diversos projetos e exercícios feitos ao longo da minha jornada de aprendizado em **Python**, desde os primeiros passos na linguagem até conteúdos mais avançados como **Programação Orientada a Objetos (POO)**, **bancos de dados**, **interfaces gráficas** com **PySide6/PyQt5**, e até **desenvolvimento web com Django**.

> 🔎 Este repositório é focado **exclusivamente em Python**, com eventuais arquivos `.html` de apoio, utilizados em bibliotecas que exigem interação com HTML.

---

## 📂 Estrutura do Repositório

Cada pasta representa uma etapa ou área de estudo específica:

| Pasta                       | Descrição                                                                  |
|-----------------------------|--------------------------------------------------------------------------- |
| `1-StartingToProgramPython` | Primeiros códigos, lógica básica e fundamentos da linguagem.               |
| `2-IntermediatePython`      | Conteúdos intermediários e introdução à Programação Orientada a Objetos.   |
| `3-POO`                     | Exercícios focados exclusivamente em Programação Orientada a Objetos.      |
| `4-ModulePython`            | Organização de código em módulos e pacotes.                                |
| `5-PySide6_PyQT5`           | Criação de interfaces gráficas com PySide6 e PyQt5.                        |
| `6-DataBaseWithPython`      | Integração com bancos de dados utilizando Python.                          |
| `7-Django`                  | Projetos iniciais com o framework Django.                                  |
| `ExercisesInGeneral`        | Exercícios diversos de fixação e revisão de conteúdos.                     |

---

## 🧠 Conceitos Estudados

- Fundamentos da linguagem Python
- Estruturas de controle e repetição
- Funções e escopos
- Manipulação de arquivos
- Programação Orientada a Objetos (POO)
- Modularização de projetos
- Interfaces gráficas com PyQt e PySide
- Conexão com banco de dados (SQLite, MySQL)
- Criação de aplicações web com Django

## 🛠 Tecnologias Utilizadas

- (Suporte com HTML em casos específicos)
